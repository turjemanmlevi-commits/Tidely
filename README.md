# Tidely

Storefront prototype for **Tidely**, a home and travel organizer brand. Everything in its place.

## Structure

| Folder | What it contains |
|---|---|
| `tidely-web/` | The website prototype: HTML, CSS and vanilla JS with GSAP and Lenis animations. Will be converted into a Shopify theme. |
| `shopify-import/images/` | Full-quality product photos (JPG) for the Shopify product import. |
| `TIDELY FOTOS/` | Original source photos (PNG). |
| `.claude/` | Design skills and the local preview config. |

## Run it locally

```bash
python -m http.server 5173 --directory tidely-web
```

Then open http://localhost:5173.
